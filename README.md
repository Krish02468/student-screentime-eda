# Student Screen Time EDA Dashboard

An exploratory data analysis of screen time patterns and their impact on student attention spans, built with Python and Streamlit.

**Dataset:** 50,000 respondents

##  Key Findings
- Average screen time: **7.1 hrs/day**
- Gaming users showed the highest attention score (3.14/4)
- Evening (6–10 PM) is the peak distraction period (5,484 low-attention cases)
- Tablet users had significantly better attention than smartphone users

---

## Features
- Interactive Streamlit dashboard with sidebar filters
- Demographic breakdown (gender, age, occupation)
- Screen time vs attention span correlation analysis
- Heatmap of distraction periods
- Full correlation matrix with Pearson r significance tests
